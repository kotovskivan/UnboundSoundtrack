01할 수 있는 것

내 노래

mp3, flac, wav, ogg, m4a — 내 제목과 커버를 단 새 트랙으로. 게임 원곡은 그대로 유지됩니다. 모드 하나에 노래 수백 곡.

YouTube · YT Music

노래, 플레이리스트, 앨범 링크를 붙여 넣거나 여러 링크, .txt 목록을 넣으면 됩니다. 다운로드는 프로그램이 알아서 합니다. 뮤직비디오 링크면 YT Music의 같은 노래를 인트로와 장면 없이 가져옵니다.

GO에 드롭

출발: 컷신 17초 + 카운트다운 3.45초, GO에 드롭이 딱 맞습니다. GO는 베이스가 들어오는 지점으로 프로그램이 자동으로 찾고, 마우스로 조정할 수 있습니다. 결승선 뒤의 짧은 구간도 설정합니다.

레이스 · 도시

게임 트랙을 레이스와 도시·차고·메뉴에서 따로 켜고 끕니다. 음악 세트별 프로필도 만들 수 있습니다. HIGH / LOW로 재생 빈도도 정할 수 있습니다.

모드 하나

Frosty Mod Manager용 모드를 하나 만듭니다. 게임 파일은 바뀌지 않습니다 — 모드를 끄면 원래대로입니다.

깨끗한 zip

zip에는 음악도 게임 파일도 없습니다. 노래는 당신의 것이고, 커버와 배경은 당신의 게임에서 읽어옵니다. ▶ — 게임 트랙 30초 미리 듣기(인터넷 필요).

02스크린샷

03필요한 것

  • Windows 10 또는 11 — Microsoft Edge가 기본 탑재되어 있고, 창이 이를 사용합니다.
  • Microsoft Visual C++ Redistributable (x64) — 필요한 파일은 zip에 이미 들어 있습니다. DLL 오류가 나면 Microsoft 공식 사이트에서 설치하세요.
  • Need for Speed Unbound — Steam 또는 EA app.
  • Frosty Mod Manager, HarGabt의 NFS Unbound 버전 — 릴리스. 한 번 실행해서 게임을 선택하세요. 처음 Launch할 때 관리자 권한을 요청하는데, 정상입니다.

04NFS Unbound에 내 음악을 넣는 방법

  1. zip 전체를 일반 폴더에 압축 해제 — 바탕 화면, 문서, D:\Mods… Program Files에는 넣지 마세요.
  2. Unbound Soundtrack.exe를 실행하고 약관에 동의하세요. 첫 실행 때 게임을 읽습니다 — 몇 분, 딱 한 번.
  3. + 노래 추가 → 파일 선택 → GO와 결승 설정 → 저장.또는 ▶ YT Music에서 → 링크 붙여 넣기(노래, 재생목록, 앨범). 여러 링크나 .txt 목록도 가능 → 다운로드.뮤직비디오 링크면 YT Music의 같은 노래를 인트로와 장면 없이 가져옵니다. 플레이리스트 전에는 곡 수, 이미 있는 곡, 시간과 용량을 보여 주고, 이미 있는 곡은 건너뜁니다. .txt 목록: 제목,아티스트,링크; (라틴 문자로) — 예시 파일은 프로그램에 있습니다.노래는 프로그램 옆의 Music 폴더에, 한 곡씩 번호 폴더로 들어 있습니다: Music\1\, Music\2\… 직접 해도 됩니다: 번호를 붙인 새 폴더에 노래 파일과 이미지를 넣으면 끝.
  4. 모드 만들기. 모드가 Frosty Mod Manager 목록에 나타납니다.
  5. Frosty Mod Manager에서 Unbound Soundtrack을 체크하고, 다른 음악 모드는 끈 뒤 Launch.

오프라인 전용

모드는 싱글 플레이용입니다. 온라인으로 하기 전에 게임을 모드 없이 실행하세요. 모드를 켠 채 온라인을 하면 EA 계정이 정지될 수 있습니다.

“Windows의 PC 보호”

유료 인증서로 서명하지 않아서 SmartScreen이 경고합니다. 추가 정보 → 실행을 누르세요. 코드는 공개되어 있습니다 — GitHub와 zip의 “source” 폴더에.

05잘 안 될 때

  • 로그: data\log.txt (창의 “로그” 버튼).
  • 처음부터 다시: 프로그램을 닫고 data 폴더를 삭제하세요.
  • 게임이 업데이트되면 프로그램이 알아서 게임을 다시 읽습니다. 그래도 모드가 만들어지지 않으면 — 여기서 새 버전을 찾아보세요.
  • 다른 음악 모드(Alternate Waves, The Lakeshore Sound)와 함께 쓸 수 없습니다 — 같은 파일을 바꾸기 때문입니다.
  • 삭제: Frosty Mod Manager에서 모드를 끄고 프로그램 폴더를 삭제하세요.
버그 신고 무엇을 했는지 적고 data\log.txt 끝부분을 붙여 넣으세요
