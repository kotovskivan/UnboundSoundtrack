01できること

自分の曲

mp3、flac、wav、ogg、m4a を、自分のタイトルとジャケット付きの新しいトラックとして追加。ゲームの曲を置き換えません。1 つの MOD に数百曲。

YouTube · YT Music

曲・プレイリスト・アルバムのリンク、複数のリンク、.txt リストを貼るだけ。ダウンロードはプログラムが自動で行います。MV のリンクなら YT Music の同じ曲を、イントロや寸劇なしで取得します。

GO でドロップ

スタート：17 秒のカットシーン + 3.45 秒のカウントダウン、GO の瞬間にドロップ。GO はベースの入りからプログラムが自動で見つけ、マウスで調整もできます。フィニッシュ用の短いパートも。

レース · 街

ゲームの曲をレース用と、街・ガレージ・メニュー用で別々にオン／オフ。音楽セットごとにプロファイルも作れます。HIGH / LOW で再生頻度も設定できます。

MOD はひとつ

Frosty Mod Manager 用の MOD をひとつ作ります。ゲームファイルは変更しません — MOD をオフにすれば元どおりです。

クリーンな zip

zip に音楽やゲームファイルは入っていません。曲はあなたのもの、ジャケットや背景はあなたのゲームから読み込みます。▶ — ゲーム内の曲を 30 秒試聴（インターネットが必要）。

02スクリーンショット

03必要なもの

  • Windows 10 または 11 — Microsoft Edge は標準搭載、ウィンドウに使います。
  • Microsoft Visual C++ Redistributable (x64) — 必要なファイルは zip に同梱済み。DLL エラーが出たら Microsoft 公式サイトからインストールしてください。
  • Need for Speed Unbound — Steam または EA app。
  • Frosty Mod Manager（HarGabt による NFS Unbound 版）— リリース。一度起動してゲームを選んでください。最初の Launch で管理者権限を求められますが、正常です。

04NFS Unbound に自分の音楽を入れる方法

  1. zip をまるごと普通のフォルダーに展開 — デスクトップ、ドキュメント、D:\Mods… Program Files には入れないでください。
  2. Unbound Soundtrack.exe を起動して規約に同意。初回起動時にゲームを読み込みます — 数分、最初の一回だけです。
  3. + 曲を追加 → ファイルを選ぶ → GO とフィニッシュを設定 → 保存。または ▶ YT Music から → リンクを貼り付け（曲、プレイリスト、アルバム）。複数のリンクや .txt リストも可 → ダウンロード。MV のリンクなら、YT Music の同じ曲をイントロや寸劇なしで取得します。プレイリストの前に、曲数・すでにある曲・時間・容量を表示し、すでにある曲はスキップします。.txt リスト：タイトル,アーティスト,リンク;（ラテン文字で）— サンプルファイルはプログラム内にあります。曲はプログラムの隣の Music フォルダーに、1 曲ずつ番号付きフォルダーで入っています：Music\1\、Music\2\… 手動でも OK：番号付きの新しいフォルダーに曲ファイルと画像を入れるだけ。
  4. MOD を作成。MOD が Frosty Mod Manager のリストに表示されます。
  5. Frosty Mod Manager で Unbound Soundtrack にチェック、ほかの音楽 MOD はオフにして Launch。

オフライン専用

MOD はシングルプレイ用です。オンラインで遊ぶ前に、MOD なしでゲームを起動してください。MOD を入れたままオンラインで遊ぶと、EA アカウントが BAN される可能性があります。

「Windows によって PC が保護されました」

有料の証明書で署名していないため、SmartScreen が警告を出します。詳細情報 → 実行 をクリックしてください。コードは公開しています — GitHub と zip 内の「source」フォルダーにあります。

05うまく動かないとき

  • ログは data\log.txt（ウィンドウの「ログ」ボタン）。
  • 最初からやり直す：プログラムを閉じて data フォルダーを削除。
  • ゲームのアップデート後は、プログラムが自動でゲームを読み直します。それでも MOD が作れない場合は、ここで新しいバージョンを探してください。
  • ほかの音楽 MOD（Alternate Waves、The Lakeshore Sound）とは併用できません — 同じファイルを変更するためです。
  • 削除：Frosty Mod Manager で MOD をオフにして、プログラムのフォルダーを削除。
バグを報告 何をしたかを書いて、data\log.txt の最後の部分を貼り付けてください
