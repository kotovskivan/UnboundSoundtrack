01Co robi

Twoje piosenki

mp3, flac, wav, ogg, m4a — jako nowe utwory z własną nazwą i okładką. Utwory gry zostają bez zmian. Setki piosenek w jednym modzie.

YouTube · YT Music

Wklej link do piosenki, playlisty albo albumu — albo wiele linków, albo listę .txt. Program sam pobierze; link do teledysku pobiera tę samą piosenkę z YT Music, bez intra i scenek.

Drop na GO

Start wyścigu: 17 s przerywnika + 3,45 s odliczania — drop wchodzi na GO. GO program znajduje sam po uderzeniu basu, poprawisz myszką. Plus krótki fragment na metę.

Wyścigi · Miasto

Włączaj i wyłączaj utwory gry osobno w wyścigach oraz w mieście, garażu i menu. Profile dla różnych zestawów muzyki. HIGH / LOW — jak często gra utwór.

Jeden mod

Buduje jeden mod do Frosty Mod Manager. Pliki gry się nie zmieniają — wyłączysz mod i gra jest jak dawniej.

Czysty zip

W zipie nie ma muzyki ani plików gry: piosenki są twoje, okładki i tła program czyta z twojej gry. ▶ — 30-sekundowy podgląd każdego utworu gry (potrzebny internet).

02Zrzuty ekranu

03Potrzebujesz

  • Windows 10 lub 11 — Microsoft Edge jest wbudowany, okno z niego korzysta.
  • Microsoft Visual C++ Redistributable (x64) — potrzebne pliki są już w zipie; jeśli program zgłosi błąd DLL, zainstaluj go z oficjalnej strony Microsoft.
  • Need for Speed Unbound — Steam lub EA app.
  • Frosty Mod Manager w wersji HarGabt dla NFS Unbound — wydania. Uruchom go raz i wybierz grę. Przy pierwszym Launch poprosi o prawa administratora — to normalne.

04Jak dodać własną muzykę do NFS Unbound

  1. Rozpakuj cały zip do zwykłego folderu — Pulpit, Dokumenty, D:\Mods… Nie do Program Files.
  2. Uruchom Unbound Soundtrack.exe i zaakceptuj warunki. Pierwsze uruchomienie czyta grę — kilka minut, tylko raz.
  3. + DODAJ PIOSENKĘ → plik → ustaw GO i metę → Zapisz.Albo ▶ Z YT MUSIC → wklej link (piosenka, playlista, album), wiele linków albo listę .txt → Pobierz.Link do teledysku — program weźmie tę samą piosenkę z YT Music, bez intra i scenek. Przed playlistą pokaże, ile piosenek, ile już masz, ile czasu i miejsca; te, które już są, pominie. Lista .txt: Tytuł,Wykonawca,Link; (alfabetem łacińskim) — przykładowy plik jest w programie.Piosenki leżą w folderze Music obok programu, każda w folderze z numerem: Music\1\, Music\2\… Można też ręcznie: nowy folder z numerem, w nim plik piosenki i obrazek.
  4. ZBUDUJ MODA. Mod pojawi się na liście Frosty Mod Manager.
  5. We Frosty Mod Manager zaznacz Unbound Soundtrack, wyłącz inne mody muzyczne, Launch.

Tylko offline

Mody są do gry jednoosobowej. Przed grą Online uruchom grę bez modów. Gra Online z modami grozi banem konta EA.

„System Windows ochronił ten komputer”

Program nie jest podpisany płatnym certyfikatem, więc SmartScreen ostrzega. Kliknij Więcej informacji → Uruchom mimo to. Kod jest otwarty — na GitHub i w folderze „source” w zipie.

05Jeśli coś nie działa

  • Log: data\log.txt (przycisk „Log” w oknie).
  • Od nowa: zamknij program i usuń folder data.
  • Po aktualizacji gry program sam przeczyta grę od nowa. Jeśli mod nadal się nie buduje — szukaj tu nowszej wersji.
  • Nie działa razem z innymi modami muzycznymi (Alternate Waves, The Lakeshore Sound) — zmieniają te same pliki.
  • Usuwanie: wyłącz mod we Frosty Mod Manager i usuń folder programu.
Zgłoś błąd opisz, co robiłeś, i wklej koniec data\log.txt
