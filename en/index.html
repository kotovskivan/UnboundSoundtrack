01What it does

Your songs

mp3, flac, wav, ogg, m4a — as new tracks with your own title and cover. The game's tracks stay as they are.

Drop on GO

For each song: the race start (the drop hits at GO) and a short piece for the finish.

Races · City

Turn the game's tracks on and off separately for races and for the city, garage and menu. Profiles for different music sets.

One mod

Builds one mod for Frosty Mod Manager. Game files are not changed — turn the mod off and the game is as before.

Clean zip

No music and no game files in the zip: the songs are yours, covers and backgrounds are read from your own game. ▶ — 30-second preview of any game track (needs internet).

03You need

  • Windows 10 or 11 — Microsoft Edge is built in, the window uses it.
  • Need for Speed Unbound — Steam or EA app.
  • Frosty Mod Manager, HarGabt's version for NFS Unbound — releases. Start it once and pick the game. On the first Launch it asks for administrator rights — that's normal.

04How to add your own music to NFS Unbound

  1. Unpack the whole zip to a normal folder — Desktop, Documents, D:\Mods… Not into Program Files.
  2. Start Unbound Soundtrack.exe and accept the terms. The first start reads the game — a few minutes, only once.
  3. + ADD SONG → choose a file → set GO and the finish → Save.Songs live in the Music folder next to the program, one numbered folder per song: Music\1\, Music\2\… By hand works too: a new numbered folder with the song file and a picture.
  4. BUILD MOD. The mod appears in Frosty Mod Manager's list.
  5. In Frosty Mod Manager: tick Unbound Soundtrack, turn off other music mods, press Launch.

Offline only

Mods are for the single-player game. Before you go Online, start the game without mods. Playing Online with mods can get your EA account banned.

“Windows protected your PC”

The program is not signed with a paid certificate, so SmartScreen warns about it. Click More info → Run anyway. The code is open — on GitHub and in the “source” folder of the zip.

05If something doesn't work

  • The log is data\log.txt (button “Log” in the window).
  • To start over: close the program and delete the data folder.
  • After a game update the program re-reads the game by itself. If building the mod still fails — check here for a newer version.
  • Not compatible with other music mods (Alternate Waves, The Lakeshore Sound) — they change the same files.
  • To remove: turn the mod off in Frosty Mod Manager and delete the program folder.
Report a bug describe what you did and paste the end of data\log.txt
