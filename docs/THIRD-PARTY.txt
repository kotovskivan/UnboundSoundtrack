---------------------------------------------------------------------
SHIPPED IN THIS FOLDER
---------------------------------------------------------------------
Frosty Toolsuite — app\frosty\ (FrostySdk, FrostyCore, FrostyHash, FrostyModSupport, FrostyControls,
  Profiles\NFSUnboundSDK.dll) — libraries to read the game and write .fbmod mods.
  License: GNU GPL v3 — https://www.gnu.org/licenses/gpl-3.0.html
  Original: https://github.com/CadeEvs/FrostyToolsuite
  NFS Unbound fork by HarGabt (the version these files come from, 1.0.7 v26.10.12):
  https://github.com/HarGabt/FrostyToolsuite

Frosty third-party libraries — app\frosty\ThirdParty\ (as shipped with Frosty Mod Manager):
  Newtonsoft.Json, zstd, LZ4, zlib, LZMA, UnRAR and others — under their own licenses.

EA audio encoder — app\encoder\Tool.exe + eaxmaenc.dll — from the Sound Editor plugin of Frosty Editor
  (HarGabt fork, same link as above). Turns your song into the game's audio format.
  With its libraries: LAME (libmp3lame.dll) — https://lame.sourceforge.io ;
  LibAtrac9 (libatrac9.dll) — https://github.com/Thealexbarney/LibAtrac9 ;
  Microsoft Visual C++ runtime (msvcr120.dll).

yt-dlp — app\yt-dlp.exe — downloads a song (sound, cover, artist and title) from a YouTube / YT Music link,
  album or playlist (the "From YT Music" button). Official release yt-dlp.exe 2026.10.26, unchanged.
  Made by the yt-dlp team (contributors of the yt-dlp project). License: The Unlicense (public domain).
  https://github.com/yt-dlp/yt-dlp

Sedgwick Ave Display font — app\web\fonts\SedgwickAveDisplay-Regular.ttf (the graffiti "Soundtrack" in the window logo). Unchanged.
  Copyright 2017 The Sedgwick Ave Project Authors. License: SIL Open Font License 1.1 — app\web\fonts\OFL-SedgwickAveDisplay.txt.
  https://github.com/googlefonts/sedgwickave

This program — Unbound Soundtrack.exe, source code in source\ — GNU GPL v3 (it uses Frosty libraries).

---------------------------------------------------------------------
PREVIEWS (online, nothing stored)
---------------------------------------------------------------------
The ▶ button plays a 30-second preview of a game track from Deezer (https://www.deezer.com, public API api.deezer.com)
or, for 2 tracks, from iTunes (https://www.apple.com/itunes/). The program keeps only the track numbers/links
(app\web\previews.json); the sound streams from their servers when you press ▶. BOIH and BOOTY have no preview
(not on Deezer/iTunes) — use the YouTube button.
