UNBOUND SOUNDTRACK  v1.0
Your own songs in Need for Speed Unbound — as separate tracks with your own covers.
Free fan-made tool by Kitivski + Claude. NOT affiliated with Electronic Arts or Criterion Games.

WHAT IT DOES
  - Turn game tracks on/off for races and for the city.
  - Add your own songs (mp3, flac, wav, ogg, m4a) as NEW tracks with your own cover.
    The game's tracks stay as they are.
  - For each song set the race start (the drop hits at GO) and the finish piece.
  - Builds ONE mod for Frosty Mod Manager. Game files are not changed.
  - ▶ on a game track — 30-second preview (Deezer, needs internet); YouTube ↗ — the full song.

YOU NEED
  - Windows 10 or 11 (Microsoft Edge is built in — the window uses it).
  - Need for Speed Unbound (Steam or EA app).
  - Frosty Mod Manager, HarGabt's version for NFS Unbound:
    https://github.com/HarGabt/FrostyToolsuite/releases
    Start it once and pick the game before using this tool.
    On its first Launch (and after the ModData folder is deleted) Frosty asks for administrator rights
    to create links to the game data ("New installation detected") — that's normal, accept it.

HOW TO USE
  1. Unpack the WHOLE zip to a normal folder (Desktop, Documents, D:\Mods…),
     not into Program Files.
  2. Start "Unbound Soundtrack.exe".
  3. Accept the terms. The first start reads the game — a few minutes, only once.
  4. + ADD SONG → choose a file → set GO and the finish → Save.
     All songs live in the "Music" folder next to the program, one numbered folder per song:
     Music\1\, Music\2\… — the order in the window. + ADD SONG creates the next folder itself.
     By hand: a new numbered folder with the song file + a picture (jpg, png) for the cover;
     GO and the finish are set automatically. Delete a folder — the song disappears from the program.
     Picture: any name if it's the only one in the folder; several — cover.jpg wins. Any size (the game uses 256x256).
  5. BUILD MOD. The mod appears in Frosty Mod Manager's list.
  6. In Frosty Mod Manager: tick "Unbound Soundtrack", turn off other music mods, press Launch.

OFFLINE ONLY
  Mods are for the single-player game. Before you go Online, start the game without mods.
  Playing Online with mods can get your EA account banned.

"WINDOWS PROTECTED YOUR PC" / "UNKNOWN PUBLISHER"
  The program is not signed with a paid certificate, so Windows SmartScreen warns about it.
  Click "More info" → "Run anyway". The source code is in the "source" folder.

WHAT IS IN THE FOLDER
  Unbound Soundtrack.exe   the program
  app\web                  the window (pages, texts in 5 languages)
  app\frosty               Frosty Toolsuite libraries — read the game, write the mod (GPL v3)
  app\encoder              EA audio encoder from Frosty Editor's Sound Editor plugin
  source\                  source code of this program (GPL v3)
  data\                    created on first start: your settings, songs, pictures read from YOUR game, log
  Music\                   your songs, one numbered folder each: song file, cover, song.json (name, GO, finish)
  THIRD-PARTY.txt          what we use, authors, licenses, links
  No files of the game or of EA are shipped: covers and backgrounds are read from your own game.

IF SOMETHING DOESN'T WORK
  - The log is data\log.txt (button "Log" in the window).
  - After a game update: the tool re-reads the game by itself. If building fails with
    "the game has changed" — look for a newer version of Unbound Soundtrack.
  - To start over: close the program and delete the "data" folder.
  - Report a bug: https://forms.gle/StNa4GFZRHckFVpi8  (describe what you did, paste the end of data\log.txt).

REMOVE
  Turn the mod off in Frosty Mod Manager and delete this folder.

WAS ES MACHT
  - Spiel-Tracks getrennt für Rennen und Stadt an-/ausschalten.
  - Eigene Songs (mp3, flac, wav, ogg, m4a) als NEUE Tracks mit eigenem Cover hinzufügen.
  - Pro Song: Rennstart (Drop bei GO) und Zielstück einstellen.
  - Baut EINEN Mod für den Frosty Mod Manager. Spieldateien bleiben unverändert.

DU BRAUCHST
  - Windows 10 oder 11 (Microsoft Edge ist eingebaut).
  - Need for Speed Unbound (Steam oder EA app).
  - Frosty Mod Manager, HarGabts Version für NFS Unbound:
    https://github.com/HarGabt/FrostyToolsuite/releases — einmal starten und das Spiel wählen.

SO GEHT'S
  1. Das GANZE Zip in einen normalen Ordner entpacken (Desktop, Dokumente, D:\Mods…), nicht nach Program Files.
  2. "Unbound Soundtrack.exe" starten, Bedingungen annehmen. Der erste Start liest das Spiel — ein paar Minuten, nur einmal.
  3. + SONG HINZUFÜGEN → Datei → GO und Ziel setzen → Speichern.
     Alle Songs liegen im Ordner "Music" neben dem Programm, jeder in einem nummerierten Ordner:
     Music\1\, Music\2\… — die Reihenfolge im Fenster. + SONG HINZUFÜGEN legt den nächsten Ordner selbst an.
     Von Hand: neuer nummerierter Ordner mit der Musikdatei + einem Bild (jpg, png) fürs Cover. Ordner gelöscht — Song ist weg.
     Bild: beliebiger Name, wenn es das einzige im Ordner ist; mehrere — cover.jpg wird genommen. Größe egal (im Spiel 256x256).
  4. MOD BAUEN → im Frosty Mod Manager "Unbound Soundtrack" anhaken, andere Musik-Mods aus, Launch.

  "Weitere Informationen" → "Trotzdem ausführen". Der Quellcode liegt im Ordner "source".

PROBLEME — Log: data\log.txt (Knopf "Log"). Neu anfangen: Programm schließen, Ordner "data" löschen.

O QUE FAZ
  - Liga/desliga as faixas do jogo separadamente nas corridas e na cidade.
  - Adiciona suas músicas (mp3, flac, wav, ogg, m4a) como faixas NOVAS com capa própria.
  - Para cada música: largada (o drop entra no GO) e trecho de chegada.
  - Gera UM mod para o Frosty Mod Manager. Os arquivos do jogo não mudam.

VOCÊ PRECISA DE
  - Windows 10 ou 11 (o Microsoft Edge já vem no sistema).
  - Need for Speed Unbound (Steam ou EA app).
  - Frosty Mod Manager, versão do HarGabt para NFS Unbound:
    https://github.com/HarGabt/FrostyToolsuite/releases — abra uma vez e escolha o jogo.

COMO USAR
  1. Descompacte o zip INTEIRO numa pasta comum (Área de Trabalho, Documentos, D:\Mods…), não em Program Files.
  2. Abra "Unbound Soundtrack.exe" e aceite os termos. A primeira vez lê o jogo — alguns minutos, só uma vez.
  3. + ADICIONAR MÚSICA → arquivo → ajuste GO e chegada → Salvar.
     Todas as músicas ficam na pasta "Music" ao lado do programa, cada uma numa pasta numerada:
     Music\1\, Music\2\… — a ordem na janela. + ADICIONAR MÚSICA cria a próxima pasta sozinho.
     À mão: nova pasta numerada com o arquivo da música + uma imagem (jpg, png) para a capa. Apagou a pasta — a música some.
     Imagem: qualquer nome se for a única na pasta; várias — usa a cover.jpg. Qualquer tamanho (no jogo 256x256).
  4. GERAR MOD → no Frosty Mod Manager marque "Unbound Soundtrack", desative outros mods de música, Launch.

SÓ OFFLINE — antes de jogar Online, abra o jogo sem mods; senão a conta EA pode ser banida.

"O WINDOWS PROTEGEU O SEU COMPUTADOR" — o programa não é assinado com certificado pago.
  Clique em "Mais informações" → "Executar assim mesmo". O código-fonte está na pasta "source".

PROBLEMAS — log: data\log.txt (botão "Log"). Recomeçar: feche o programa e apague a pasta "data".
  Relatar um bug: https://forms.gle/StNa4GFZRHckFVpi8  (descreva o que fez, cole o final de data\log.txt).
