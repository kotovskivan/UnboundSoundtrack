UNBOUND SOUNDTRACK  v1.0.1
Свои песни в Need for Speed Unbound — как новые треки со своими обложками.
Бесплатная фанатская программа от Kitivski + Claude. НЕ связана с Electronic Arts и Criterion Games.
Сайт: https://kotovskivan.github.io/UnboundSoundtrack/

English — README.txt рядом с программой.
Переводы сделаны ИИ (Claude).

=====================================================================
ЧТО УМЕЕТ
  - Включать/выключать треки игры отдельно для гонок и для города.
  - Добавлять свои песни (mp3, flac, wav, ogg, m4a) как НОВЫЕ треки со своей обложкой.
    Треки игры остаются как есть.
  - Песни с YouTube / YT Music: ссылка на песню, плейлист или альбом, много ссылок сразу или список в .txt.
    Если ссылка на клип, программа берет ту же песню из YT Music — без вставок и сценок из клипа.
  - Для каждой песни — старт гонки (17 с катсцены + 3,45 с отсчета, дроп бьет на GO) и кусок для финиша.
  - HIGH / LOW на карточке — как часто играет трек (игра сначала берет HIGH).
  - Профили: разные наборы треков, переключение в один клик.
  - Собирает ОДИН мод для Frosty Mod Manager. Файлы игры не меняются.
  - ▶ на треке игры — послушать 30 секунд (Deezer, нужен интернет); YouTube ↗ — песня целиком.
  - Окно говорит на 13 языках.

ЧТО НУЖНО
  - Windows 10 или 11 (Microsoft Edge уже встроен — окно работает на нем).
  - Need for Speed Unbound (Steam или EA app).
  - Frosty Mod Manager, версия HarGabt для NFS Unbound:
    https://github.com/HarGabt/FrostyToolsuite/releases
    Запусти его один раз и выбери игру, прежде чем пользоваться этой программой.
    При первом запуске он просит ключ шифрования игры — NFS Unbound Encryption Key:
    https://www.nexusmods.com/needforspeedunbound/mods/97
    Когда первый раз нажмешь Launch (и после удаления папки ModData), Frosty просит права администратора,
    чтобы создать ссылки на данные игры ("New installation detected") — это нормально, соглашайся.

КАК ПОЛЬЗОВАТЬСЯ
  1. Распакуй ВЕСЬ zip в обычную папку (Рабочий стол, Документы, D:\Mods…),
     не в Program Files.
  2. Запусти "Unbound Soundtrack.exe".
  3. Выбери язык, прими условия. Первый запуск читает игру — несколько минут, только один раз.
  4. + ДОБАВИТЬ ПЕСНЮ → выбери файл → поставь GO и финиш → Сохранить.
     Или ▶ ИЗ YT MUSIC → вставь ссылку (песня, плейлист, альбом) → Скачать.
     Все песни лежат в папке "Music" рядом с программой, каждая в своей папке с номером:
     Music\1\, Music\2\… — это порядок в окне. + ДОБАВИТЬ ПЕСНЮ сама создает следующую папку.
     Вручную: новая папка с номером, в ней файл песни + картинка (jpg, png) для обложки;
     GO и финиш программа поставит сама. Удалил папку — песня исчезнет из программы.
     Картинка: название любое, если она в папке одна; несколько — берется cover.jpg. Размер любой (в игре 256x256).
  5. СОБРАТЬ МОД. Мод появится в списке Frosty Mod Manager.
  6. В Frosty Mod Manager: поставь галочку на "Unbound Soundtrack", другие музыкальные моды выключи, нажми Launch.

ТОЛЬКО ОФЛАЙН
  Моды — для одиночной игры. Прежде чем идти в онлайн, запускай игру без модов.
  Игра онлайн с модами — риск бана аккаунта EA.

"СИСТЕМА WINDOWS ЗАЩИТИЛА ВАШ КОМПЬЮТЕР" / "НЕИЗВЕСТНЫЙ ИЗДАТЕЛЬ"
  Программа не подписана платным сертификатом, поэтому Windows SmartScreen о ней предупреждает.
  Нажми "Подробнее" → "Выполнить в любом случае". Исходный код — в папке "source".

ЧТО В ПАПКЕ
  Unbound Soundtrack.exe   программа
  app\web                  окно (страницы, тексты на 13 языках)
  app\frosty               библиотеки Frosty Toolsuite — читают игру, записывают мод (GPL v3)
  app\encoder              аудиокодировщик EA из плагина Sound Editor для Frosty Editor
  app\yt-dlp.exe           качает песни с YouTube / YT Music (Unlicense)
  source\                  исходный код этой программы (GPL v3)
  README\                  этот текст на других языках
  data\                    появляется при первом запуске: твои настройки, песни, картинки из ТВОЕЙ игры, лог
  Music\                   твои песни, каждая в папке с номером: файл песни, обложка, song.json (название, GO, финиш)
  THIRD-PARTY.txt          что используем, авторы, лицензии, ссылки
  Файлов игры и EA в архиве нет: обложки и фоны читаются из твоей собственной игры.

ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
  - Лог — data\log.txt (кнопка "Лог" в окне).
  - После обновления игры программа сама перечитает игру. Если сборка падает с ошибкой
    "Игра изменилась" — поищи более новую версию на сайте.
  - Начать заново: закрой программу и удали папку "data".
  - Сообщить о баге: https://forms.gle/StNa4GFZRHckFVpi8  (опиши, что делал, и вставь конец data\log.txt).

КАК УДАЛИТЬ
  Выключи мод в Frosty Mod Manager и удали папку с программой.
