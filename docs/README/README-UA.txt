UNBOUND SOUNDTRACK  v1.0.1
Свої пісні в Need for Speed Unbound — як нові треки зі своїми обкладинками.
Безкоштовна фанатська програма від Kitivski + Claude. НЕ пов'язана з Electronic Arts чи Criterion Games.
Сайт: https://kotovskivan.github.io/UnboundSoundtrack/

English — README.txt поруч із програмою.
Переклади зроблені ШІ (Claude).

=====================================================================
ЩО ВМІЄ
  - Вмикати/вимикати треки гри окремо для гонок і для міста.
  - Додавати свої пісні (mp3, flac, wav, ogg, m4a) як НОВІ треки зі своєю обкладинкою.
    Треки гри лишаються як є.
  - Пісні з YouTube / YT Music: посилання на пісню, плейлист чи альбом, багато посилань разом або список у .txt.
    Якщо посилання на кліп, програма бере ту саму пісню з YT Music — без вставок і сценок із кліпу.
  - Для кожної пісні — старт гонки (17 с катсцени + 3,45 с відліку, дроп б'є на GO) і шматок для фінішу.
  - HIGH / LOW на картці — як часто грає трек (гра спершу бере HIGH).
  - Профілі: різні набори треків, перемикання в один клік.
  - Збирає ОДИН мод для Frosty Mod Manager. Файли гри не змінюються.
  - ▶ на треку гри — 30 секунд послухати (Deezer, потрібен інтернет); YouTube ↗ — пісня повністю.
  - Вікно розмовляє 13 мовами.

ЩО ПОТРІБНО
  - Windows 10 або 11 (Microsoft Edge вже вбудований — вікно працює на ньому).
  - Need for Speed Unbound (Steam або EA app).
  - Frosty Mod Manager, версія HarGabt для NFS Unbound:
    https://github.com/HarGabt/FrostyToolsuite/releases
    Запусти його один раз і обери гру, перш ніж користуватися цією програмою.
    Під час першого запуску він просить ключ шифрування гри — NFS Unbound Encryption Key:
    https://www.nexusmods.com/needforspeedunbound/mods/97
    Коли вперше натиснеш Launch (і після видалення папки ModData), Frosty просить права адміністратора,
    щоб створити посилання на дані гри ("New installation detected") — це нормально, погоджуйся.

ЯК КОРИСТУВАТИСЯ
  1. Розпакуй УВЕСЬ zip у звичайну папку (Робочий стіл, Документи, D:\Mods…),
     не в Program Files.
  2. Запусти "Unbound Soundtrack.exe".
  3. Обери мову, прийми умови. Перший запуск читає гру — кілька хвилин, лише раз.
  4. + ДОДАТИ ПІСНЮ → обери файл → постав GO і фініш → Зберегти.
     Або ▶ З YT MUSIC → встав посилання (пісня, плейлист, альбом) → Завантажити.
     Усі пісні лежать у папці "Music" поруч із програмою, кожна в папці з номером:
     Music\1\, Music\2\… — це порядок у вікні. + ДОДАТИ ПІСНЮ сама створює наступну папку.
     Вручну: нова папка з номером, у ній файл пісні + картинка (jpg, png) для обкладинки;
     GO і фініш програма поставить сама. Видалив папку — пісня зникне з програми.
     Картинка: назва будь-яка, якщо вона в папці одна; кілька — береться cover.jpg. Розмір будь-який (у грі 256x256).
  5. ЗІБРАТИ МОД. Мод з'явиться у списку Frosty Mod Manager.
  6. У Frosty Mod Manager: постав галочку на "Unbound Soundtrack", інші музичні моди вимкни, натисни Launch.

ТІЛЬКИ ОФЛАЙН
  Моди — для одиночної гри. Перш ніж іти в онлайн, запускай гру без модів.
  Гра онлайн з модами — ризик бану акаунта EA.

"WINDOWS ЗАХИСТИВ ВАШ ПК" / "НЕВІДОМИЙ ВИДАВЕЦЬ"
  Програма не підписана платним сертифікатом, тому Windows SmartScreen про неї попереджає.
  Натисни "Докладніше" → "Однаково запустити". Вихідний код — у папці "source".

ЩО В ПАПЦІ
  Unbound Soundtrack.exe   програма
  app\web                  вікно (сторінки, тексти 13 мовами)
  app\frosty               бібліотеки Frosty Toolsuite — читають гру, записують мод (GPL v3)
  app\encoder              аудіокодувальник EA з плагіна Sound Editor для Frosty Editor
  app\yt-dlp.exe           качає пісні з YouTube / YT Music (Unlicense)
  source\                  вихідний код цієї програми (GPL v3)
  README\                  цей текст іншими мовами
  data\                    з'являється при першому запуску: твої налаштування, пісні, картинки з ТВОЄЇ гри, лог
  Music\                   твої пісні, кожна в папці з номером: файл пісні, обкладинка, song.json (назва, GO, фініш)
  THIRD-PARTY.txt          що використовуємо, автори, ліцензії, посилання
  Файлів гри чи EA в архіві немає: обкладинки й фони читаються з твоєї власної гри.

    "Гра змінилася" — пошукай новішу версію на сайті.
