01Что умеет

Свои песни

mp3, flac, wav, ogg, m4a — как новые треки, со своим названием и обложкой, а не вместо треков игры. Сотни песен в одном моде.

YouTube · YT Music

Вставь ссылку на песню, плейлист или альбом — или много ссылок, или список .txt. Программа скачает сама; если ссылка на клип — возьмет ту же песню из YT Music, без вступлений и сценок.

Дроп на GO

Старт гонки: 17 с катсцены + 3,45 с отсчета — дроп бьет на GO. GO программа находит сама по удару баса, подправишь мышкой. Плюс короткий кусок для финиша.

Гонки · Город

Включай и выключай треки игры отдельно для гонок и для города, гаража и меню. Профили для разных наборов музыки. HIGH / LOW — как часто играет трек.

Один мод

Собирает один мод для Frosty Mod Manager. Файлы игры не меняются — выключил мод, и игра как была.

Чистый zip

В zip нет ни музыки, ни файлов игры: песни — твои, обложки и фоны программа читает из твоей игры. ▶ — 30-секундное превью любого трека игры (нужен интернет).

02Скриншоты

03Что нужно

  • Windows 10 или 11 — Microsoft Edge уже встроен, окно работает на нем.
  • Microsoft Visual C++ Redistributable (x64) — нужные файлы уже есть в zip; если программа скажет об ошибке DLL — установи с официального сайта Microsoft.
  • Need for Speed Unbound — Steam или EA app.
  • Frosty Mod Manager, версия HarGabt для NFS Unbound — релизы. Запусти его один раз и выбери игру. Первый Launch попросит права администратора — это нормально.

04Как добавить свои песни в NFS Unbound

  1. Распакуй весь zip в обычную папку — Рабочий стол, Документы, D:\Mods… Не в Program Files.
  2. Запусти Unbound Soundtrack.exe и прими условия. Первый запуск читает игру — несколько минут, только один раз.
  3. + ДОБАВИТЬ ПЕСНЮ → выбери файл → поставь GO и финиш → Сохранить.Или ▶ ИЗ YT MUSIC → вставь ссылку (песня, плейлист, альбом), много ссылок или список .txt → Скачать.Ссылка на клип — программа возьмет ту же песню из YT Music, без вступлений и сценок. Перед плейлистом покажет, сколько песен, сколько уже есть, сколько времени и места; те, что уже есть, пропустит. Список .txt: Название,Исполнитель,Ссылка; (латиницей) — пример файла есть в программе.Песни лежат в папке Music рядом с программой, каждая в папке с номером: Music\1\, Music\2\… Можно и вручную: новая папка с номером, в ней файл песни и картинка.
  4. СОБРАТЬ МОД. Мод появится в списке Frosty Mod Manager.
  5. В Frosty Mod Manager: галочка на Unbound Soundtrack, другие музыкальные моды выключи, Launch.

Только офлайн

Моды — для одиночной игры. Перед онлайном запускай игру без модов. Онлайн с модами — риск бана аккаунта EA.

«Система Windows защитила ваш компьютер»

Программа не подписана платным сертификатом, поэтому SmartScreen предупреждает. Нажми Подробнее → Выполнить в любом случае. Код открыт — на GitHub и в папке «source» в zip.

05Если не работает

  • Лог — data\log.txt (кнопка «Лог» в окне).
  • Начать заново: закрой программу и удали папку data.
  • После обновления игры программа сама перечитает игру. Если мод все равно не собирается — ищи новую версию здесь.
  • Не совместима с другими музыкальными модами (Alternate Waves, The Lakeshore Sound) — они меняют те же файлы.
  • Удалить: выключи мод в Frosty Mod Manager и удали папку программы.
Сообщить о баге опиши, что делал, и вставь конец data\log.txt
