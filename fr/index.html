01Ce que ça fait

Tes chansons

mp3, flac, wav, ogg, m4a — comme nouveaux titres avec ton nom et ta pochette, sans remplacer les titres du jeu. Des centaines de chansons dans un seul mod.

YouTube · YT Music · Spotify

Colle le lien d'une chanson, d'une playlist ou d'un album — ou plusieurs liens, ou une liste .txt. Le programme télécharge tout seul ; un lien de clip prend la même chanson sur YT Music, sans intro ni saynètes. Un lien Spotify marche aussi : la liste vient de Spotify, les chansons de YT Music.

Drop sur le GO

Départ : 17 s de cinématique + 3,45 s de compte à rebours — le drop tombe sur le GO. Le programme trouve le GO tout seul grâce au coup de basse, tu l'ajustes à la souris. Et un court passage pour l'arrivée.

Courses · Ville · Garage

Active ou désactive les titres séparément pour les courses, la ville et le garage — une chanson peut même passer seulement au garage. Des profils pour différentes playlists. HIGH / LOW — à quelle fréquence un titre passe.

Un seul mod

Crée un seul mod pour Frosty Mod Manager. Les fichiers du jeu ne changent pas — désactive le mod et le jeu redevient comme avant.

Zip propre

Ni musique ni fichiers du jeu dans le zip : les chansons sont à toi, pochettes et fonds sont lus depuis ton propre jeu. ▶ — aperçu de 30 secondes de n'importe quel titre du jeu (Internet requis).

02Captures d'écran

03Il te faut

  • Windows 10 ou 11 — Microsoft Edge est intégré, la fenêtre l'utilise.
  • Microsoft Visual C++ Redistributable (x64) — les fichiers nécessaires sont déjà dans le zip ; si le programme signale une erreur de DLL, installe-le depuis le site officiel de Microsoft.
  • Need for Speed Unbound — Steam ou EA app.
  • Frosty Mod Manager, version de HarGabt pour NFS Unbound — téléchargements. Lance-le une fois et choisis le jeu. Au premier Launch, il demande les droits administrateur — c'est normal.

04Comment ajouter ta propre musique dans NFS Unbound

  1. Décompresse le zip entier dans un dossier normal — Bureau, Documents, D:\Mods… Pas dans Program Files.
  2. Lance Unbound Soundtrack.exe et accepte les conditions. Le premier lancement lit le jeu — quelques minutes, une seule fois.
  3. + AJOUTER UNE CHANSON → choisis un fichier → règle le GO et l'arrivée → Enregistrer.Ou ▶ DEPUIS YT MUSIC → colle un lien (chanson, playlist, album), plusieurs liens ou une liste .txt → Télécharger.Lien de clip — le programme prend la même chanson sur YT Music, sans intro ni saynètes. Avant une playlist, il montre combien de chansons, combien tu en as déjà, le temps et la place ; celles que tu as déjà sont sautées. Liste .txt : Titre,Artiste,Lien; (lettres latines) — le programme montre un fichier d'exemple.Les chansons sont dans le dossier Music à côté du programme, chacune dans un dossier numéroté : Music\1\, Music\2\… À la main aussi : un nouveau dossier numéroté avec le fichier de la chanson et une image.
  4. CRÉER LE MOD. Le mod apparaît dans la liste de Frosty Mod Manager.
  5. Dans Frosty Mod Manager : coche Unbound Soundtrack, désactive les autres mods de musique, Launch.

Hors ligne uniquement

Les mods sont pour le jeu en solo. Avant de jouer en ligne, lance le jeu sans mods. Jouer en ligne avec des mods peut faire bannir ton compte EA.

« Windows a protégé votre ordinateur »

Le programme n'est pas signé avec un certificat payant, donc SmartScreen affiche un avertissement. Clique sur Informations complémentaires → Exécuter quand même. Le code est ouvert — sur GitHub et dans le dossier « source » du zip.

05Si ça ne marche pas

  • Le log : data\log.txt (bouton « Log » dans la fenêtre).
  • Repartir de zéro : ferme le programme et supprime le dossier data.
  • Après une mise à jour du jeu, le programme relit le jeu tout seul. Si le mod ne se crée toujours pas — cherche ici une version plus récente.
  • Incompatible avec les autres mods de musique (Alternate Waves, The Lakeshore Sound) — ils modifient les mêmes fichiers.
  • Désinstaller : désactive le mod dans Frosty Mod Manager et supprime le dossier du programme.
Signaler un bug décris ce que tu as fait et colle la fin de data\log.txt
