01Was es macht

Deine Songs

mp3, flac, wav, ogg, m4a — als neue Tracks mit eigenem Namen und Cover, nicht anstelle der Tracks des Spiels. Hunderte Songs in einem Mod.

YouTube · YT Music

Füg einen Link zu einem Song, einer Playlist oder einem Album ein — oder viele Links, oder eine .txt-Liste. Das Programm lädt selbst herunter; ein Musikvideo-Link holt denselben Song von YT Music, ohne Intro und Szenen.

Drop bei GO

Rennstart: 17 s Zwischensequenz + 3,45 s Countdown — der Drop kommt bei GO. GO findet das Programm selbst am Bass-Einsatz, mit der Maus korrigierbar. Dazu ein kurzes Stück fürs Ziel.

Rennen · Stadt

Spiel-Tracks getrennt für Rennen und für Stadt, Garage und Menü an- und ausschalten. Profile für verschiedene Musik-Sets. HIGH / LOW — wie oft ein Track läuft.

Ein Mod

Baut einen Mod für den Frosty Mod Manager. Spieldateien bleiben unverändert — Mod aus, und alles ist wie vorher.

Sauberes Zip

Keine Musik und keine Spieldateien im Zip: die Songs sind deine, Cover und Hintergründe liest das Programm aus deinem Spiel. ▶ — 30-Sekunden-Vorschau jedes Spiel-Tracks (braucht Internet).

03Du brauchst

  • Windows 10 oder 11 — Microsoft Edge ist eingebaut, das Fenster nutzt ihn.
  • Microsoft Visual C++ Redistributable (x64) — die nötigen Dateien sind schon im Zip; meldet das Programm einen DLL-Fehler, installier es von der offiziellen Microsoft-Seite.
  • Need for Speed Unbound — Steam oder EA app.
  • Frosty Mod Manager, HarGabts Version für NFS Unbound — Releases. Einmal starten und das Spiel wählen. Beim ersten Launch fragt er nach Administratorrechten — das ist normal.

04So kommt deine eigene Musik in NFS Unbound

  1. Das ganze Zip in einen normalen Ordner entpacken — Desktop, Dokumente, D:\Mods… Nicht nach Program Files.
  2. Unbound Soundtrack.exe starten und die Bedingungen annehmen. Der erste Start liest das Spiel — ein paar Minuten, nur einmal.
  3. + SONG HINZUFÜGEN → Datei → GO und Ziel setzen → Speichern.Oder ▶ AUS YT MUSIC → Link einfügen (Song, Playlist, Album), viele Links oder eine .txt-Liste → Herunterladen.Musikvideo-Link — das Programm nimmt denselben Song von YT Music, ohne Intro und Szenen. Vor einer Playlist zeigt es, wie viele Songs, wie viele du schon hast, Zeit und Platz; vorhandene werden übersprungen. .txt-Liste: Titel,Interpret,Link; (lateinische Buchstaben) — eine Beispieldatei gibt es im Programm.Die Songs liegen im Ordner Music neben dem Programm, jeder in einem nummerierten Ordner: Music\1\, Music\2\… Geht auch von Hand: neuer nummerierter Ordner mit Musikdatei und Bild.
  4. MOD BAUEN. Der Mod erscheint in der Liste des Frosty Mod Managers.
  5. Im Frosty Mod Manager Unbound Soundtrack anhaken, andere Musik-Mods aus, Launch.

Nur offline

Mods sind fürs Einzelspieler-Spiel. Vor dem Online-Spiel das Spiel ohne Mods starten. Online mit Mods droht eine Sperre des EA-Kontos.

„Der Computer wurde durch Windows geschützt“

Das Programm ist nicht mit einem kostenpflichtigen Zertifikat signiert, deshalb warnt SmartScreen. Weitere Informationen → Trotzdem ausführen. Der Code ist offen — auf GitHub und im Ordner „source“ im Zip.

05Wenn etwas nicht geht

  • Log: data\log.txt (Knopf „Log“ im Fenster).
  • Neu anfangen: Programm schließen, Ordner data löschen.
  • Nach einem Spiel-Update liest das Programm das Spiel selbst neu ein. Klappt das Bauen trotzdem nicht — hier nach einer neueren Version schauen.
  • Nicht kompatibel mit anderen Musik-Mods (Alternate Waves, The Lakeshore Sound) — sie ändern dieselben Dateien.
  • Entfernen: Mod im Frosty Mod Manager ausschalten und den Programmordner löschen.
Fehler melden beschreib, was du gemacht hast, und füg das Ende von data\log.txt ein
